# thaw-app community policies

Default policies for repositories in the thaw-app organization:

- [Contributing](.github/CONTRIBUTING.md).
- [Security Policy](.github/SECURITY.md).
- [Code of Conduct](.github/CODE_OF_CONDUCT.md).

GitHub uses these defaults when a repository has no local file of the same type. Local copies in the root, `.github/`, or `docs/` override them. Keep product-specific instructions in files such as `docs/CONTRIBUTOR_NOTES.md` and `docs/SECURITY_NOTES.md` instead.

Repository settings and `CODEOWNERS` are managed by [platform](https://github.com/thaw-app/platform). Policy text is maintained here. This repository does not enable checks, configure branch protection, or turn on private vulnerability reporting by itself.
